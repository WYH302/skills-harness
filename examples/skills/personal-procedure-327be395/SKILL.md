# 面向新手评估一个开源工具是否值得采用

## 触发条件

当任务需要「面向新手评估一个开源工具是否值得采用」所描述的交付物，且输入和步骤适用时使用。

## 输入

- 输入：项目仓库链接、预期用途和可投入的安装时间。

## 执行步骤

1. 先确认用户的实际用途、已有工具和能接受的安装维护成本。
2. 读取仓库说明、许可证和最近的发布记录，记录每一项判断的公开来源。
3. 区分仓库宣称的功能与实际文档或运行记录能够支持的功能。
4. 比较候选工具与现有方案在目标任务、配置要求和维护投入方面的差异。
5. 给出采用、暂缓或替代方案的建议，并明确哪些功能尚未验证。

## 个人要求

- 以后就按这种结构交付，结论中保留尚未验证的部分。

## 输出

- 输出：用途说明、证据对比表、安装成本和采用建议。

## 例外和纠正

- 如果输入、目标或操作条件不匹配，先调整流程，不照搬特定任务中的值。
