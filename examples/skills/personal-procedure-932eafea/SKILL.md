# 围绕研究问题分析长文档并交付证据报告

## 触发条件

当任务需要「围绕研究问题分析长文档并交付证据报告」所描述的交付物，且输入和步骤适用时使用。

## 输入

- 输入：文档文件、研究问题和所需报告语言。

## 执行步骤

1. 先明确需要回答的研究问题，以及最后报告要支持的决策。
2. 根据目录和关键词定位相关章节，记录章节号和原文页码。
3. 提取能够直接支持问题的原文证据，保留引用位置和必要的上下文。
4. 把不同章节的证据整理成比较表，区分文档事实、作者主张和自己的推断。
5. 依据证据回答问题，并列出文档没有提供答案的部分。

## 个人要求

- 以后就按这种结构交付，结论中保留尚未验证的部分。

## 输出

- 输出：问题对应的证据表、引用位置、结论和未知项。

- 如果输入、目标或操作条件不匹配，先调整流程，不照搬特定任务中的值。
